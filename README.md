# NOIR RIVER Poker

Онлайн-покер для живых игроков на игровые фишки.

- **Игры:** Техасский холдем No-Limit и Омаха Pot-Limit (кэш-столы и турниры Sit & Go), дурак подкидной и переводной на фишки, блэкджек против дилера.
- **Админ-панель** на `/admin`.
- **Столы:** на 2, 6 или 9 мест.
- **Стек:** Node.js + Express + Socket.IO на сервере, чистый HTML/CSS/JS на клиенте без сборки.

## Быстрый старт

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

После запуска откройте:

- http://localhost:3000 — лендинг;
- http://localhost:3000/play — сама игра.

Чтобы сыграть с самим собой, откройте вторую вкладку в режиме инкогнито или другой браузер и зарегистрируйте второго игрока. Если играете с друзьями в одной сети, им нужен адрес `http://<IP вашего компьютера>:3000/play`.

```bash
npm test     # 43 теста: покер, турниры, дурак (4000 партий), блэкджек (2000 раундов), админка, сокет-сервер
npm run dev  # перезапуск сервера при изменении файлов
```

## Сыграть с друзьями через интернет за 2 минуты

Без хостинга и регистрации: сервер работает на вашем компьютере, а бесплатный Cloudflare Tunnel даёт ему публичный HTTPS-адрес.

**Windows:** дважды кликните `start-online.bat`. Скрипт сам:
1. поставит зависимости;
2. скачает `cloudflared.exe`;
3. запустит сервер и туннель.

В окне появится адрес вида `https://xxxx.trycloudflare.com`. Друзьям отправьте его с `/play` на конце.

**Если Cloudflare не подключается** (в логе `QUIC connection failed` / `HTTP/2 connection is blocked`), значит провайдер режет порты туннеля. Запустите `start-online-ssh.bat`: он поднимает туннель через SSH на порту 443 (pinggy.io, без регистрации) и даёт ссылку вида `https://xxxx.a.pinggy.link`.

**macOS / Linux:** установите `cloudflared` (`brew install cloudflared`) и запустите `./start-online.sh`.

Учтите:
- Адрес меняется при каждом запуске.
- Компьютер и оба окна должны оставаться включёнными, пока вы играете.
- Для постоянного адреса нужен VPS (раздел «Деплой на сервер») или именованный туннель Cloudflare со своим доменом.

## Постоянная база данных (чтобы аккаунты не пропадали)

Без настройки игра хранит данные в файле `data/users.json`. На бесплатном Render этот файл стирается при каждом засыпании сервера. Чтобы данные сохранялись, подключите бесплатный PostgreSQL:

1. Зарегистрируйтесь на **neon.tech** (бесплатный тариф, банковская карта не нужна) и создайте проект.
2. На главной странице проекта нажмите **Connect** и скопируйте строку подключения вида `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`.
3. В Render откройте сервис, затем **Environment → Add Environment Variable**: имя `DATABASE_URL`, значение — скопированная строка. Сохраните, Render перезапустит игру.
4. В логах появится строка `База данных: PostgreSQL`. Таблицы создаются автоматически.

Подойдёт любой PostgreSQL: Supabase, Render Postgres или свой сервер. Сохраняются только изменившиеся записи. Фишки, которые были за столами в момент перезапуска, возвращаются на балансы.

## Что умеет

**Аккаунты**
- Регистрация по нику и паролю. Пароли хранятся как хеш scrypt, сессии — как токены.
- Стартовый баланс 10 000 фишек.
- Ежедневный бонус 2 000 фишек.

**Варианты покера**
- Холдем No-Limit (NLH) и Fixed-Limit (LHE: ставка = BB на префлопе и флопе, 2 BB на тёрне и ривере, не больше 4 ставок за улицу).
- Шорт-дек 6+: колода 36 карт, флеш старше фулл-хауса, сет старше стрита, A-6-7-8-9 — младший стрит.
- Омаха Pot-Limit (4 карты) и Омаха-5 (5 карт, до 6 игроков): ровно 2 карты с руки + 3 с борда.

**Шансы за столом** (кнопка «Шансы»)
- Текущая комбинация, шанс выиграть против оставшихся соперников и вероятность собрать каждую комбинацию к риверу.
- Считается в браузере методом Монте-Карло только по своим картам и борду — чужие карты не используются, преимущества не даёт.

**Лобби**
- Картинки-плитки игр: покер, турниры, дурак, блэкджек.
- Постоянные столы всех вариантов покера.
- Создание своего стола: игра, блайнды, число мест.
- Фильтры, таблица лидеров, список «Мои столы».

**Турниры Sit & Go**
- Четыре формата: Турбо 6-max, Дуэль 1 на 1, Омаха 6-max, Большой стол на 9.
- Регистрация списывает бай-ин, отмена до старта возвращает его.
- Старт, как только стол заполнен; места рассаживаются случайно.
- Блайнды растут каждые 5 раздач (14 уровней).
- Призы: 1 место — 100% (дуэль), 65/35% (6-max), 50/30/20% (9-max).
- Как только турнир стартует, сразу открывается регистрация в следующий такой же.
- Отошедший игрок не задерживает стол: карты сбрасываются автоматически.
- При остановке сервера остаток призового фонда делится по фишкам.

**Конструктор турниров (админка → Турниры)**
- Название, вариант покера, мест (2–9, в Омахе-5 до 6), бай-ин (0 — фриролл), гарантия фонда.
- Стартовый стек, стартовые блайнды, раздач на уровень, время на ход (10–120 с), свои выплаты в процентах, например `50, 30, 20`.
- Старт, как только стол полон, или по расписанию (дата и время + минимум игроков; если не набралось — отмена с возвратом).
- Повтор: после старта открывается такой же турнир, а турнир по расписанию переносится на следующий день.
- «Начать сейчас» — запуск с теми, кто уже зарегистрировался (от 2 игроков). Форматы сохраняются в базе, их можно копировать и удалять.

**Рост блайндов на кэш-столах**
- При создании стола можно выбрать: не повышать, каждые 3, 5 или 10 раздач.
- Над столом видно уровень и с какой раздачи будут следующие блайнды.
- Опустевший стол возвращается к начальным блайндам. В лобби есть постоянный стол «Разгон» с ростом каждые 5 раздач.

**Дурак**
- Подкидной и переводной, 2–6 игроков, колода 36 карт, козырь — нижняя карта колоды.
- Первым ходит игрок с младшим козырем; в первом отбое не больше 5 карт, дальше не больше 6 и не больше, чем карт у отбивающегося.
- Подкидывают все, кроме отбивающегося; «Беру» — можно подкинуть вдогонку; в переводном — перевод картой того же достоинства.
- Ставка: каждый вносит её при раздаче, дурак теряет ставку, остальные делят банк; ничья возвращает ставки.
- 30 секунд на ход; кто не успел — автоход (заход младшей картой / «Беру» / пас). Три пропуска подряд — поражение, уход из партии — тоже.
- Партия начинается, когда все за столом нажали «Готов».

**Блэкджек**
- До 5 боксов за столом против дилера, 6 колод, после ¾ шуза — новая перетасовка.
- Блэкджек платит 3:2, дилер стоит на всех 17 и сразу проверяет блэкджек при тузе или десятке.
- Удвоение на любых двух картах (и после сплита), сплит до 4 рук, тузы после сплита получают по одной карте.
- Ставки фишками-номиналами, «Повторить», 12 секунд на ставки (раздача раньше, если поставили все). Клавиши H/S/D/P.
- Три стола: 5–250, 10–1 000, 100–10 000. Ставка в раунде учтена «в игре» и вернётся при падении сервера.

**Кнопки ставок в покере**
- Под ползунком: ×2, ×2,5, ×3, ×4 от текущей ставки (префлоп без рейзов — от большого блайнда).
- Кнопка 3-бет / 4-бет / 5-бет — сервер считает рейзы на улице; плюс ⅓, ½, ¾ банка, банк, олл-ин. Под каждой кнопкой — итоговая сумма.

**Рулетка** (европейская, одно зеро)
- Общий стол до 8 игроков, три постоянных стола (фишка от 5 / 10 / 100), можно создать свой, в том числе приватный.
- Ставки: число (35:1), дюжины и колонны (2:1), красное/чёрное, чёт/нечет, 1–18/19–36 (1:1). На телефоне поле поворачивается вертикально.
- Таймер ставок стартует с первой фишки (15 с), затем 7 с вращения: колесо и шарик останавливаются на выпавшем номере. Номер выбирается на сервере криптостойким генератором.
- Кнопки «Отменить», «Очистить», «Повторить», «Удвоить», история последних номеров.

**Шашки** (русские)
- Доска на двоих, ставка с каждого (50–5 000), победитель забирает банк, ничья возвращает ставки, цвета меняются каждую партию.
- Полные правила: обязательное взятие до конца, летающие дамки, превращение во время взятия, турецкий удар. Ничья по соглашению, после 15 ходов дамками без взятий или при трёхкратном повторе.
- Шахматные часы 3, 5 или 10 минут + 3 секунды за ход, «Сдаться», «Предложить ничью», запись партии.

**Задания и награды** (панель в лобби)
- Каждый день 3 задания (по московскому времени): одно по покеру, одно по дураку или блэкджеку, одно любое. За каждое — 600–1 200 фишек.
- За каждое из 14 достижений — награда от 500 до 25 000 фишек, кнопка «Забрать» в лобби и в профиле.

**Турниры от игроков**
- Во вкладке «Турниры» любой игрок нажимает «Создать турнир»: игра, мест, бай-ин, стек, блайнды, время на ход, выплаты, старт по заполнению или по времени.
- Можно добавить в фонд свои фишки; при отмене (организатором, админом или если не набралось игроков) они и бай-ины возвращаются. Не больше 2 открытых турниров на игрока.

**Профиль и статистика** (`#/profile`, клик по нику в лидерах или у друга)
- Аватар: своя картинка (PNG/JPEG/WebP/GIF до 1 МБ, обрезается в круг) или 10 цветов и 10 значков; ник в чате окрашен в цвет аватара (масти, корона, звезда, молния, луна, пламя), виден за всеми столами.
- Статистика по покеру, турнирам, дураку и блэкджеку; место в рейтинге.
- График фишек по дням, лента последних игр (раздачи за одним столом сгруппированы).
- 14 достижений с прогрессом.

**Личные сообщения**
- Кнопка с облачком в шапке открывает панель «Сообщения»: диалоги с последним сообщением и счётчиком непрочитанных, ниже — друзья, кому ещё не писали.
- Написать можно из списка друзей (иконка рядом с другом) и из профиля друга. Видно «в сети», «печатает…», дни и время сообщений.
- Писать можно только друзьям, до 500 символов; хранятся последние 200 сообщений каждого диалога (в базе вместе с остальными данными).

**Меню игр**
- Слева в лобби — меню игр; при наведении всплывает баннер игры с описанием и счётчиком игроков. На планшете меню сворачивается в иконки, на телефоне — в полосу под шапкой.
- «Все игры» (`#/games`) — отдельная страница с большими баннерами всех шести игр.

**Друзья и приватные столы**
- Заявки в друзья по нику, список друзей: кто онлайн и за каким столом, кнопка «К столу».
- Кнопка «Пригласить» на любом столе: ссылка для копирования и «Позвать» онлайн-друзей — у них всплывает приглашение с кнопкой «Присоединиться».
- Приватные столы (покер, дурак, блэкджек): не видны в общем лобби, их видят только создатель и его друзья, зайти можно по ссылке.

**Админ-панель (`/admin`)**
- Кто админ: ники из переменной `ADMIN_NAMES`. Если она не задана — первый зарегистрированный аккаунт.
- Обзор: кто онлайн, фишки на балансах и в игре, активные раздачи и партии, журнал действий админов.
- Игроки: начислить/списать фишки, запретить чат, сбросить пароль, сделать админом, заблокировать (игрока убирает со всех столов).
- Покер: создать стол (в т. ч. постоянный), сменить блайнды и их рост, убрать игрока, очистить чат, закрыть стол с возвратом фишек.
- Турниры: конструктор (см. выше), открыть ещё один, начать сейчас, отменить (возврат бай-инов или раздел фонда по фишкам).
- Дурак: создать, убрать игрока, очистить чат, закрыть с возвратом ставок.
- Блэкджек: создать стол с нужными лимитами, убрать игрока, очистить чат, закрыть с возвратом ставок.
- Объявления: полоса с текстом у всех игроков.

**Игра**
- Блайнды, баттон и правила хедз-апа.
- Минимальный рейз. Неполный олл-ин не открывает торговлю заново.
- Пот-лимит в Омахе.
- Побочные банки и возврат неуравненной ставки.
- Дележ банка; нечётная фишка уходит первому слева от баттона.
- Комбинации в Омахе считаются строго как 2 карты с руки + 3 с борда.

**Честность**
- Колода тасуется на сервере алгоритмом Фишера–Йетса с `crypto.randomInt`.
- Клиент получает только свои карты. Чужие карты он видит лишь на вскрытии.
- Тест `test/rng.test.js` раздаёт сотни тысяч рук и сверяет частоты комбинаций с теорией (хи-квадрат). Для 7 карт Холдема: пара или лучше — ~83% раздач, две пары — 23,5%, сет — 4,8%, стрит — 4,6%, флеш — 3%. Поэтому «комбинация почти в каждой раздаче» — это нормальная математика, а не подкрутка.

**Таймер хода**
- 25 секунд на ход.
- Если время вышло, срабатывает авто-чек или фолд, а игрок помечается как «отошёл».

**Обрыв связи**
- Место держится 90 секунд.
- При перезагрузке страницы игра продолжается с того же места.

**Фишки не теряются**
- Если встать из-за стола посреди раздачи, игрок сбрасывает карты, а его стек возвращается после её окончания.
- При остановке сервера (Ctrl+C) все стеки возвращаются на балансы.
- При аварийном падении сервера стеки возвращаются при следующем запуске.

**Интерфейс**
- Анимации: карты разлетаются от центра при раздаче, борд переворачивается, сброшенные карты уходят в центр, ставки съезжают в банк, банк — к победителю, кнопка дилера едет по столу.
- Звуки действий синтезируются в браузере (без файлов), есть выключатель.
- Аватары с инициалами.
- Действия заранее: «Чек/Фолд», «Чек», «Колл N», «Колл любую».
- Горячие клавиши: F — фолд, C — чек/колл, R — бет/рейз.
- «Показать карты» после раздачи, выигранной без вскрытия.
- Вкладка «Раздачи»: последние 20 раздач с результатом и пошаговым повтором.
- Чат, лог стола, пресеты ставок: ½, ¾ банка, банк, олл-ин.
- Адаптив под компьютер, планшет и телефон (в том числе горизонтальный).

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `DATA_FILE` | `data/users.json` | где хранить пользователей |
| `ACTION_TIME_MS` | `25000` | время на ход |
| `RECONNECT_GRACE_MS` | `90000` | сколько держать место при обрыве связи |
| `SNG_LEVEL_HANDS` | `5` | сколько раздач длится уровень блайндов в турнирах |
| `ADMIN_NAMES` | — | ники администраторов через запятую |
| `DATABASE_URL` | — | строка подключения PostgreSQL; без неё — файл `DATA_FILE` |

## Деплой на сервер

```bash
docker build -t noir-river .
docker run -d -p 3000:3000 -v noir-data:/app/data noir-river
```

Без Docker приложение можно запустить через `pm2 start server/index.js`.

## Ограничения текущей версии

- **Один процесс.** Столы живут в памяти одного сервера (аккаунты — в PostgreSQL или файле). Для сотен одновременных игроков этого хватит; для нескольких серверов понадобится Redis-адаптер Socket.IO.
- **Нет ботов и многостоловых турниров (MTT).** Есть только одностоловые Sit & Go. Rush-покер на лендинге помечен как «скоро».
- **Админка без двухфакторной защиты.** Задайте `ADMIN_NAMES` на сервере, доступном из интернета, иначе админом станет первый зарегистрировавшийся.
- **Только игровые фишки.** Игра на реальные деньги требует лицензии оператора, KYC/AML, сертификации генератора случайных чисел и платёжного провайдера. Это отдельный проект.
